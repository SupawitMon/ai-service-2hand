# วิธีต่อโมเดลจริงเข้ากับหน้า mockup

ไฟล์ชุดนี้ทำให้หน้า `mockup_ai_price.html` **เรียกใช้โมเดลที่เทรนไว้จริง**
(`best.pt` = YOLO ตรวจเกรด, `price_model.json` = XGBoost ทายราคา) แทนตัวเลขที่คำนวณเล่นๆ ใน JavaScript

## ทำไมต้องมี "backend" เพิ่ม

`price_model.json` ที่ให้มาต้องการข้อมูล **37 อย่าง** ถึงจะทายราคาได้ (ราคาตลาดเฉลี่ย,
คะแนนผู้ขาย, รายละเอียดความเสียหาย ฯลฯ) แต่หน้าฟอร์มยังกรอกแค่ ยี่ห้อ/รุ่น/ปี/เกรด/อุปกรณ์ครบไหม
ตาม workflow ที่ต้องการความง่าย

`backend_server.py` จึงทำหน้าที่เป็นตัวกลาง — พอเลือกยี่ห้อ+รุ่น มันจะไปดึงข้อมูลราคาตลาด/สเปค
ของสินค้ารุ่นนั้นจาก `product_lookup.json` (คำนวณเฉลี่ยไว้ล่วงหน้าจาก dataset เดิม) มาเติมให้เอง
ส่วนข้อมูลความเสียหายจะแปลงมาจากเกรด A/B/C ที่ได้จากรูป

## ไฟล์ที่ต้องมีอยู่ในโฟลเดอร์เดียวกัน

```
backend_server.py          <- ตัวเซิร์ฟเวอร์ (ไฟล์ใหม่)
product_lookup.json        <- ฐานข้อมูลราคาตลาดอ้างอิง (ไฟล์ใหม่)
mockup_ai_price.html       <- หน้าเว็บ (อัปเดตแล้ว ให้เรียก backend)
price_model.json           <- โมเดล XGBoost (ไฟล์ที่คุณอัปโหลดมา)
price_model_categories.pkl <- (ไฟล์ที่คุณอัปโหลดมา)
best.pt                    <- โมเดล YOLO (ไฟล์ที่คุณอัปโหลดมา)
```

**สำคัญ:** ย้ายไฟล์ `price_model.json`, `price_model_categories.pkl`, `best.pt` (3 ไฟล์เดิมที่คุณมี)
มาไว้ในโฟลเดอร์เดียวกับไฟล์ใหม่ทั้งหมดนี้ก่อน

## วิธีรัน

**1) ติดตั้งเครื่องมือ (ครั้งเดียว)**
```
pip install -r requirements_backend.txt
```

**2) รัน backend**
```
python backend_server.py
```
รอจนเห็นข้อความ `โหลด price_model.json สำเร็จ` และ `Running on http://0.0.0.0:5000` — **อย่าปิดหน้าต่างนี้** เปิดทิ้งไว้ตลอดเวลาที่ใช้งาน

**3) เปิดหน้าเว็บ**
เปิดไฟล์ `mockup_ai_price.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย หรือคลิกขวา Open with Chrome)
ตอนนี้หน้าเว็บจะดึงรายชื่อยี่ห้อ/รุ่นจาก backend จริง และเวลากดปุ่ม "ประเมินราคาเลย"
ก็จะเรียกโมเดล XGBoost จริงมาคำนวณ ไม่ใช่เลขสุ่มอีกต่อไป

## หมายเหตุเรื่อง YOLO

ถ้า `ultralytics` ติดตั้งไม่สำเร็จ หรือ `best.pt` โหลดไม่ขึ้น backend จะยังทำงานได้ปกติ
(ทายราคาได้) แค่ส่วน "AI ตรวจสภาพจากรูป" จะขึ้นข้อความให้เลือกเกรดเอง แทนที่จะเดาอัตโนมัติ

## ข้อจำกัดที่ควรรู้

เลือกได้เฉพาะยี่ห้อ+รุ่นที่**มีอยู่ในข้อมูล training เดิม** (293 รุ่น) เท่านั้น เพราะราคาตลาด
อ้างอิงต้องดึงจากข้อมูลเก่า ถ้าเป็นสินค้ารุ่นใหม่ที่ไม่เคยมีในระบบ จะต้องเพิ่มข้อมูลราคาตลาด
ของรุ่นนั้นเข้าไปใน `product_lookup.json` เองก่อน (หรือเทรนโมเดลใหม่โดยรวมข้อมูลรุ่นนั้นเข้าไปด้วย)
